Reconciliare

Política de Privacidade

Introdução

O Reconciliare é um aplicativo católico de preparação para a confissão. Levamos a privacidade dos nossos usuários muito a sério, especialmente considerando a natureza sensível e espiritual dos dados envolvidos.

Resumo: O Reconciliare não coleta, armazena ou compartilha seus dados com terceiros. Todas as informações ficam exclusivamente no seu dispositivo.

Dados Armazenados

O aplicativo armazena localmente no seu dispositivo:

  • Nome: Para personalização do app
  • PIN de acesso: Armazenado de forma segura e criptografada
  • Exame de consciência: Suas marcações durante o exame
  • Histórico de confissões: Datas e anotações pessoais
  • Preferências: Tema visual e idioma escolhido

Segurança dos Dados

Implementamos medidas rigorosas de segurança:

  • Criptografia AES: Todos os dados sensíveis são criptografados
  • Armazenamento seguro: O PIN é protegido pelo sistema de segurança nativo do dispositivo
  • Sem transmissão: Nenhum dado é enviado pela internet
  • Controle total: Você pode apagar todos os dados a qualquer momento

O Que NÃO Fazemos

  • Não coletamos dados pessoais
  • Não enviamos dados para servidores externos
  • Não usamos ferramentas de analytics ou rastreamento
  • Não compartilhamos informações com terceiros
  • Não exibimos anúncios
  • Não usamos identificadores de publicidade

Permissões do Aplicativo

O Reconciliare solicita apenas as seguintes permissões:

  • Calendário: Para agendar lembretes de confissão (opcional)

Nenhuma outra permissão é necessária ou solicitada.

Backup e Exportação

O aplicativo permite exportar seus dados em formato criptografado para backup pessoal. Este arquivo fica sob sua responsabilidade e controle total.

Contato

Para dúvidas sobre esta política de privacidade ou sobre o aplicativo, entre em contato através do repositório do projeto no GitHub.
